MP3 ПЛЕЕР — виджет для рабочего стола
=====================================

Запуск без сборки:   run.bat          (нужен Python 3.10+)
Собрать .exe:        build.bat   ->   dist\MP3Player\MP3Player.exe
                     (папка целиком: exe + _internal; так плеер запускается быстро)

Управление
----------
Кнопки сбоку (сверху вниз):
  1  — предыдущий трек  (удерживать — перемотка назад)
  2  — играть / пауза
  3  — следующий трек   (удерживать — перемотка вперёд)
  4  — перемешивание вкл / выкл
Клик по экрану         — плейлист (поиск, клик по треку — играть)
Клик по колпачку сверху — снять колпачок: USB-режим с настройками
Клик по полоске прогресса — перемотка (можно тянуть; при наведении видно время)
Клик по низу плеера (серебристая часть) — следующая сохранённая папка
Колёсико мыши          — громкость
Alt + колёсико         — размер плеера (или меню «📏 Размер»)
Shift + тянуть мышью   — повернуть плеер (у 0°/90°/180° «прилипает»)
Shift + колёсико       — повернуть на 5°; готовые углы — меню «🔄 Поворот»
                         (−90° — горизонтально, текст на экране ровный)
Ctrl + колёсико        — перемотка ±5 сек
Тянуть за корпус       — переместить плеер
Перетащить папку/файлы на плеер — загрузить музыку
Правый клик            — меню: открыть папку, повтор, размер,
                         «только на рабочем столе / поверх окон»,
                         автозапуск с Windows, выход
Иконка в трее          — показать/спрятать, средний клик — пауза

Медиа-клавиши и Windows
-----------------------
Медиа-клавиши клавиатуры и наушников (⏯ ⏭ ⏮) управляют плеером.
Плеер появляется во всплывающей панели громкости Windows с названием и обложкой,
и его видят другие программы (например, Music → Discord для статуса).

Горячие клавиши (работают из любого окна, отключаются в меню):
  Ctrl+Alt+Пробел  — играть / пауза
  Ctrl+Alt+→ / ←   — следующий / предыдущий
  Ctrl+Alt+↑ / ↓   — громкость
  Ctrl+Alt+S       — перемешивание
  Ctrl+Alt+P       — показать / спрятать плеер
  Ctrl+Alt+L       — плейлист
  Ctrl+Alt+F       — следующая папка
  Ctrl+Alt+A       — повтор A–B (A, B, сброс)
  Ctrl+Alt+K       — ♥ в избранное / убрать
  Ctrl+Alt+I       — итоги на экране
  Ctrl+Alt+M       — мини-режим / большой плеер
  Ctrl+Alt+R       — радио / обратно к музыке
Если сочетание уже занято другой программой, в меню будет пометка «занято».

Обложка
-------
При смене трека рядом с плеером на несколько секунд всплывает карточка
с обложкой альбома (из тегов файла), названием и исполнителем.
Наведи мышь — не исчезнет, кликни — спрячется. Выключается в меню.

«Сейчас играет»
---------------
Когда плеер спрятан в трей, при смене трека в правом нижнем углу экрана
всплывает уведомление с обложкой. Клик по нему — показать плеер.
В меню можно выбрать: «Когда плеер спрятан» / «Всегда» / «Выключено».

Плавность (меню «🎚 Плавность»)
-------------------------------
Затухание при паузе — звук мягко уходит и возвращается.
Переход между треками — в конце трека следующий начинается поверх затихающего
(кроссфейд). Длина: выкл / 2 / 4 / 6 / 8 сек, по умолчанию 4.
При ручном переключении треков — короткий мягкий переход.

Закладки в длинных файлах
-------------------------
Для файлов длиннее 20 минут (подкасты, аудиокниги) плеер помнит, где ты
остановился, — отдельно для каждого файла. При возврате к файлу игра
продолжается чуть раньше этого места (на 3 сек), на экране «ПРОДОЛЖЕНИЕ».
Дослушанный до конца файл забывается. Выключается в меню «🔖».

Мои папки (меню «📁 Мои папки»)
-------------------------------
Каждая открытая папка сохраняется в список. Переключение — из меню,
кликом по низу плеера или Ctrl+Alt+F. Для каждой папки помнится свой
трек и место в нём. Лишнюю папку можно убрать из списка.

Экран (меню «📟 Экран»)
-----------------------
При запуске — заставка как у настоящего плеера: экран мигает при включении,
тест сегментов полосками, «HELLO» по буквам и полоска загрузки.
Клик по плееру — пропустить. При выходе — «BYE» и экран гаснет.
Во время игры на экране прыгают столбики эквалайзера с «пиками».
Оба эффекта отключаются в меню; там же «Показать заставку сейчас».

Колпачок и USB-режим
--------------------
Клик по тёмному колпачку — он с щелчком «отлетает» вверх и висит над плеером,
открывая USB-штекер. На экране — меню настроек, как в настоящем плеере:
  кнопка 1 — вверх, кнопка 2 — OK (изменить), кнопка 3 — вниз,
  кнопка 4 — надеть колпачок обратно.
Можно и кликать по пунктам на экране, и крутить колёсико.
Клик по колпачку или штекеру — надеть обратно. Музыка при этом продолжает играть.
В меню: подсветка, звук кнопок, эквалайзер, заставка, переход, затухание,
закладки, обложка, размер, где показывать, открыть папку.

Подсветка: зелёная, голубая, оранжевая, красная, белая
(в USB-меню или «📟 Экран → Подсветка»). Цвет подхватывают и плейлист,
и всплывающие окна.

Звук кнопок: короткие щелчки при нажатии и отпускании, «чпок» колпачка.
Выключается в USB-меню или «📟 Экран → Звук кнопок».

Если плеер не видно
-------------------
* Запусти MP3Player ещё раз — уже работающий плеер сам выйдет на передний план.
* Или кликни по его иконке в трее (у часов, может прятаться под стрелкой ^).
* Если при запуске что-то сломалось, появится окно с ошибкой, а подробности —
  в файле %APPDATA%\MP3Player\error.log (пришли его).
Режим «Только на рабочем столе» — плеер обычное окно, которое не всплывает поверх
программ при клике: живёт под их окнами и виден, когда они свёрнуты.

Скины (меню «🎨 Скин»)
----------------------
Встроенные: Флешка (со снимающимся колпачком), Кассетный (катушки крутятся,
клавиши сверху, динамик — следующая папка), Карманный (крестовина: ⏮ ⏯ ⏭,
вверх — меню настроек, вниз — перемешать), Полночь (сине-неоновый).
У скинов без колпачка настройки на экране открывает кнопка ⚙ (меню).
Размер и подсветка запоминаются для каждого скина свои.

Свой скин: «🎨 Скин → Свой скин из картинки…». Выбери PNG/JPG плеера,
по шагам обведи мышкой экран и кнопки (необязательные можно пропустить).
Если у картинки сплошной фон — отметь «Убрать фон» и подбери допуск.
Готовый скин лежит в %APPDATA%\MP3Player\skins\<название>\
(body.png + skin.json — разметку можно поправить руками).

Текст песни (.lrc) — меню «🎤 Текст песни»
-----------------------------------------
Где плеер ищет .lrc (по порядку):
  1. ручная привязка: «📎 Привязать .lrc к этому треку…» или просто перетащи .lrc на плеер;
  2. рядом с треком (то же имя) или в подпапке Lyrics;
  3. в «папках с текстами» (с подпапками) — по имени: регистр, ё/е, номер трека,
     скобки вроде «(Reload)», дефисы и знаки не мешают;
  4. там же — по тегам [ar:] / [ti:] внутри .lrc.
Папки добавляются в «🎤 Текст песни → ➕ Добавить папку с .lrc…».
Если текст не в такт — «⏪ раньше / ⏩ позже на 0,5 с» (запоминается для трека).
Текущая строка «заливается» в такт, ниже — следующая; понимает UTF-8 и Windows-1251.

Звуки (📟 Экран → Звуки)
------------------------
«Писк» — твой звук из заставки: на нажатие кнопок и при включении плеера.
«Щелчки» — прежние щелчки пластмассовых кнопок + короткий сигнал включения.
Громкость звуков: тихо / средне / громко (там же, или «ГРОМК. ЗВУКОВ» в меню на экране).
Свои звуки: «Папка своих звуков…» и положи туда WAV с именами
  beep.wav (писк), boot.wav (включение), click_down.wav / click_up.wav (щелчки),
  cap_off.wav / cap_on.wav (колпачок). Подхватываются при следующем запуске.

Настоящий спектр
----------------
Эквалайзер слушает саму музыку (нужен PySide6 6.8+, его ставит build.bat).
Если не работает — сам переключается на декоративный.
В меню на экране «ЭКВАЛАЙЗЕР»: СПЕКТР / ДЕКОР / ВЫКЛ.

Win+D
-----
В режиме «Только на рабочем столе» плеер встаёт поверх, когда активен сам
рабочий стол (после Win+D или клика по обоям), и уходит под окно программы,
как только её активируешь. Вкл/выкл: «🖥 Где показывать → Не прятаться по Win+D».

Диагностика
-----------
Меню → «🛠 Диагностика…» показывает, что работает на этом компьютере
(спектр, Win+D, медиа-клавиши). Кнопка «Копировать» — чтобы прислать текст.

Повтор A–B (для разучивания)
----------------------------
Удерживай кнопку ⏯ ~полсекунды: 1-й раз — точка A, 2-й — точка B
(кусок A–B начинает крутиться по кругу), 3-й — сброс.
То же: Ctrl+Alt+A из любого окна или меню «🅰🅱 Повтор A–B».
На экране — значок A–B, на полоске прогресса — засечки и подсвеченный кусок.
При смене трека повтор сбрасывается.

Избранное ❤
-----------
Двойной клик по экрану (или Ctrl+Alt+K) — трек в избранное / убрать.
На экране у избранного трека горит ♥, в плейлисте — ♥ и фильтр «только избранное».
«❤ Избранное → Слушать избранное» — все ♥-треки из всех папок одним списком;
ещё раз — вернуться к папке. То же в меню на экране («ИЗБРАННОЕ»).
Одиночный клик по экрану по-прежнему открывает плейлист (с маленькой задержкой).

Итоги 📊
--------
Плеер сам считает, сколько ты слушаешь (прослушивание = 30 сек или полтрека).
«📊 Итоги → Показать на экране» (или Ctrl+Alt+I, или «ИТОГИ» в меню на экране):
  неделя столбиками по дням (сегодня мерцает), топ треков, топ исполнителей, всего.
Листать: ⏮ / ⏭, колёсико или клик по экрану; любая другая кнопка — выйти.
Статистика лежит в %APPDATA%\MP3Player\stats.json, сбросить — в меню «📊 Итоги».

Discord (вместе с Music → Discord)
----------------------------------
Плеер пишет, что играет, в %APPDATA%\MP3Player\nowplaying.json, а Music → Discord
показывает это в статусе как «MP3 Плеер»: точное время, текст из твоих .lrc,
чёрный список по папкам. Вкл/выкл: меню «🎮 Показывать в Discord» или «DISCORD»
в меню на экране. ♥ в избранное — Ctrl+Alt+K (Ctrl+Alt+H — невидимка Music → Discord).

Открывать музыку двойным кликом (меню «🔗 Открывать музыку в MP3 Плеере»)
-----------------------------------------------------------------------
«➕ Добавить…» — плеер появится в «Открыть с помощью» у MP3/FLAC/…, а в меню
проводника — «▶ Играть в MP3 Плеере» (для файлов и для папок).
«⭐ Сделать плеером по умолчанию…» — Windows 10/11 позволяет выбрать программу
по умолчанию только самому пользователю: откроется нужная страница настроек
(или: правый клик по MP3 → «Открыть с помощью» → «Выбрать другое приложение» →
MP3 Плеер → «Всегда»).
Открыл один файл — играет он сразу (без заставки), а плейлист — эта папка (без подпапок); выделил несколько —
плейлист из них. Если плеер уже запущен, файл откроется в нём (вторая копия не нужна).
Всё пишется только для твоей учётной записи и убирается пунктом «✖ Убрать плеер из Windows».
Если перенесёшь MP3Player.exe в другую папку — пути обновятся сами при запуске.

3D-корпус (📟 Экран → 3D-корпус)
-------------------------------
«Флешка» и «Полночь» — круглые трубки: лицо (экран, кнопки, текст) натянуто на цилиндр,
каждая полоска освещена по своему углу, бок и спина — гладкий металл.
Остальные скины — бруски с толщиной (бока строятся по контуру картинки).
Тянешь плеер — он поворачивается по ходу движения, отпускаешь — покачивается и встаёт ровно.
Ctrl + тянуть — покрутить в руках (трубку — хоть на все 360°); отпустил — пружинит обратно.
«3D: наклоняться за курсором» — лёгкий наклон к мышке, когда она над плеером.
В skin.json: "shape": "cylinder" (+ "axis_x", "radius") — трубка, иначе брусок ("depth" — толщина).
Когда плеер стоит ровно, он рисуется как обычно — без нагрузки.

Мини-режим (меню «▭ Мини-режим», Ctrl+Alt+M)
---------------------------------------------
Плеер сворачивается в полоску: ЖК-окошко (бегущее название, время, прогресс —
по нему можно кликнуть для перемотки) и кнопки ⏮ ⏯ ⏭; ⤢ или двойной клик
по окошку — обратно в большой плеер. Полоску можно таскать, колёсико — громкость,
правый клик — то же меню. Место и режим запоминаются.

Интернет-радио (меню «📻 Радио», Ctrl+Alt+R)
---------------------------------------------
Станции переключаются как треки: ⏮ / ⏭, плейлист, клик по экрану.
Название песни плеер читает прямо из потока: оно на экране, в уведомлениях,
в панели Windows и в Discord (Music → Discord подберёт обложку по названию).
Внизу экрана вместо прогресса — мигающий «● LIVE · название станции».
Оборвалась связь — плеер сам переподключается к той же станции.
Добавить станцию: «➕ по ссылке» или открыть/перетащить на плеер .m3u / .pls.
«↩ Вернуться к музыке» — к папке, где был. Станции по умолчанию можно убирать.

Скачать в плеер через Doulander (меню «⬇ Скачать в плеер», Ctrl+Alt+D)
---------------------------------------------------------------------
Вставь ссылку (YouTube, VK, SoundCloud…) или просто «Исполнитель — песня» —
трек скачается в текущую папку и сразу появится в плейлисте; если ничего не играло —
заиграет. Ссылку можно и перетащить из браузера прямо на плеер.
Скопированная ссылка подставляется в окно сама. Кнопка «⬇ скачать» есть и в плейлисте.
Пока качается — на экране «DL 42%». Несколько ссылок встают в очередь.
Плеер берёт из папки Doulander его yt-dlp, ffmpeg и настройки: формат музыки
и качество, квадратная обложка, тексты .lrc, cookies и прокси для YouTube.
Doulander ищется в %LOCALAPPDATA%\Programs\Downloader; если он в другом месте —
«⬇ Скачать в плеер → Где Doulander?» и укажи Downloader.exe.

Тексты из интернета (меню «🎤 Текст песни»)
--------------------------------------------
Если своего .lrc у трека нет, плеер сам ищет синхронный текст на lrclib.net
(по исполнителю, названию, альбому и длительности) и сохраняет его рядом с треком
как «Трек.lrc» — дальше он работает без интернета и виден в Discord.
Нельзя писать в папку с музыкой — сохранит в %APPDATA%\MP3Player\lyrics и привяжет.
«🌐 Найти текст в интернете» — искать сейчас (и для трека, где не нашлось раньше);
галочка «Искать тексты в интернете сам» — выключить автопоиск.
Ненайденные треки повторно ищутся не чаще раза в неделю.

Автообновление (меню «⬆ Обновления»)
-------------------------------------
Сборки с GitHub (SevereClaw/MP3-Player → Releases) плеер ставит сам: раз в 6 часов
проверяет, скачивает в фоне и обновляется, когда музыка не играет 2 минуты
(или при выходе). «Проверить сейчас» — скачать и поставить сразу.
Собранное у себя через build.bat не обновляется (номера сборки нет).

Плеер запоминает папку, трек, позицию, громкость и место на экране
(%APPDATA%\MP3Player\settings.json).
Форматы: mp3, flac, wav, ogg, opus, m4a, aac, wma, aiff.
