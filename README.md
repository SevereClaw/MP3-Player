# MP3 Плеер

Плеер-виджет для рабочего стола Windows в виде MP3-плеера: без фона, кнопки сбоку,
скины (в том числе 3D), тексты песен, радио, статус в Discord через Music → Discord,
скачивание треков через Doulander.

## Скачать

**[Releases → последняя сборка → MP3Player.zip](../../releases/latest)**

Распакуй куда удобно и запусти `MP3Player.exe`. Папку `_internal` держи рядом с exe.
Python ставить не нужно.

Новая сборка появляется сама после каждого изменения в репозитории (GitHub Actions,
вкладка **Actions**). Обновиться: закрой плеер (трей → «Выход») и распакуй новый
архив поверх старой папки — настройки хранятся отдельно, в `%APPDATA%\MP3Player`.

## Собрать у себя

`build.bat` (нужен Python 3.10+), готовое — в `dist\MP3Player`.

Подробности обо всех функциях — в [README.txt](README.txt).
